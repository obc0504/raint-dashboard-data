컬럼: 상품명, 상품번호, 기간(YYYY.MM.DD), 결제건수, 유입수, 구매전환율(%), 주문건수, 주문금액, 취소주문건수, 취소주문금액.
전환율 = 주문건수 ÷ 유입수. 대시보드·자동 갱신 스크립트와는 연결돼 있지 않고, 코드로만 조회합니다.

파일명은 `시작일_종료일`이고, 기간이 서로 겹칩니다(같은 날짜·상품이 여러 파일에 있음). 합칠 때는 날짜+상품번호 기준으로 중복을 제거하세요.

### 2026-11-11 파일 형식 변경 (네이버 방문분석)
- 컬럼 앞에 `날짜 기준`(조회기간 / 비교기간)이 추가됨(16컬럼). 비교기간 행은 전주 같은 요일 등 비교용으로 함께 내려오는 데이터.
- `네이버_방문분석_센티카_2026-11-11_11-11.xlsx`: 조회기간 11/11(방문 348 / 결제 32 / 837,810원, 상품 84행)과 비교기간 11/4(59행)가 같이 들어 있다.

- 사용 규칙: `날짜 기준`이 있으면 `조회기간` 행만 사용, 날짜+채널상품번호로 중복 제거.
