# 올리브영 매출 엑셀 (센티카)

월별 누적 엑셀(월 1파일, 올려줄 때마다 같은 달 파일은 최신본으로 갱신). **양식은 이 파일 양식을 계속 사용**한다.

## 시트 구성
| 시트 | 내용 | 비고 |
|---|---|---|
| 오프라인매출 | 상품별 일(1~31일) 수량·금액 | **필요(온라인/오프라인/총매출)** |
| 온라인몰 | 상품별 일 수량·금액 | **필요** |
| 총매출 | 상품별 일 수량·금액 | **필요**. 총매출 = 온라인몰 + 오프라인매출 (검산 일치) |
| 매장별 매출 | 일자별 매장명·매출금액(총합 + 순위) | 참고 |
| 온라인(주문건) | 기준일·상품코드·상품명·단품명·주문액·결제총합·쿠폰·판매수량 | 참고 |

- 상품 시트 헤더: 3행(순번, 상품코드, 상품명, 1일~31일 각각 수량/금액), 마지막에 '합 계' 행, 상품 19행. 빈 칸('')은 판매 없음.
- 금액은 원 단위(부가세 포함 여부는 올리브영 양식 기준, 확인 필요).
